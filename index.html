Jeton d'accès (PAT)

Un jeton fine-grained, restreint au seul dépôt Tiktok_Auto, avec les permissions Actions et Contents en lecture/écriture. Il reste uniquement dans ce navigateur — jamais envoyé ailleurs qu'à GitHub.

Comment créer ce jeton (une seule fois)

Lien direct : github.com/settings/personal-access-tokens/new — dans un navigateur, l'application GitHub n'expose pas cette page.

  1. Token name : ce que tu veux
  2. Expiration : 90 jours par exemple
  3. Repository access : Only select repositories → Tiktok_Auto
  4. Permissions → Repository permissions :
    Actions : Read and write
    Contents : Read and write
  5. Generate token, copie-le : GitHub ne le réaffichera jamais

À propos

Cette page est un fichier statique hébergé publiquement par GitHub Pages — elle ne contient aucun secret. Elle parle en direct à l'API GitHub avec le jeton collé ci-dessus, qui reste dans le stockage local de ce navigateur.
