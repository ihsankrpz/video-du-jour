Jeton d'accès (PAT)

Un jeton fine-grained, restreint au seul dépôt Tiktok_Auto, avec les permissions Actions et Contents en lecture/écriture. Il reste uniquement dans ce navigateur — jamais envoyé ailleurs qu'à GitHub.

Comment créer ce jeton (une seule fois)
  1. github.com → photo de profil → Settings
  2. Developer settings (tout en bas) → Personal access tokens → Fine-grained tokens
  3. Generate new token
  4. Resource owner : ton compte
  5. Repository access : Only select repositories → Tiktok_Auto
  6. Permissions → Repository permissions :
    Actions : Read and write
    Contents : Read and write
  7. Expiration : 90 jours, par exemple — GitHub te rappellera de le renouveler
  8. Generate token, puis copie-le ici. Il ne sera plus jamais réaffiché par GitHub.

À propos

Cette page est un simple fichier statique, hébergé publiquement par GitHub Pages — elle ne contient aucun secret. Elle parle en direct à l'API GitHub avec le jeton que tu as collé ci-dessus, qui reste dans le stockage local de ce navigateur.
